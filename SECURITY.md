# Güvenlik politikası

## Desteklenen sürüm

Yalnızca en son GitHub sürümü güvenlik düzeltmeleri için desteklenir.

## Güvenlik açığı bildirme

Hassas ayrıntıları herkese açık issue içine yazmayın. Deponun **Security** sekmesindeki **Report a vulnerability** seçeneğiyle özel bildirim gönderin. Bu özellik kullanılamıyorsa ayrıntı paylaşmadan kısa bir issue açıp özel iletişim kanalı isteyin.

Bildirimde etkilenen sürümü, yeniden üretme adımlarını, beklenen etkiyi ve varsa önerilen düzeltmeyi belirtin. Gerçek kullanıcı verisi, kimlik bilgisi veya izinsiz erişilmiş içerik eklemeyin.

## Dosya doğrulama

Yayınlanan EXE kod imzalı değildir. Sürüm dosyasını yalnızca bu deponun **Releases** bölümünden indirin ve SHA-256 değerini sürüm notundaki değerle karşılaştırın. Antivirüs uyarısını aşmak için güvenlik ürününü kapatmayın.
