# Değişiklik günlüğü

## 0.3.1 — 2026-09-28

- Uygulama arayüzüne görünür **GoodbyeDPI Auto by Tuğrul** geliştirici kredisi eklendi.
- Dosya sürümü, uygulama manifesti ve günlük başlığı 0.3.1 olarak güncellendi.
- Windows ikili dosya metadatası genişletildi.
- Control Flow Guard ve yüksek entropili ASLR derleme korumaları etkinleştirildi.

## 0.3.0 — 2026-09-28

- Bağlantı, hedefler, işlem kaydı ve kullanım paneli baştan tasarlandı.
- Kurulu hizmet ve seçilen profil ana ekranda görünür hale getirildi.
- Boş DNS yedeğinde görülen Windows 87 kodlama hatası giderildi.
- IPv6 varsayılan rotası olmayan bağlantılarda IPv6 DNS işlemi atlanıyor.
- Windows hizmeti oluşturma hatalarının ayrıntısı korunuyor.
- Yönetici yetkisi uygulama manifestine taşındı.
- ASLR, yüksek entropili ASLR, NX ve Control Flow Guard derleme korumaları etkinleştirildi.
- Çevrimdışı C++, DNS ve ImGui test kapsamı genişletildi.

## 0.2.3 — 2026-09-28

- Türkiye ana profili ve altı alternatif için otomatik sıralı tarama tamamlandı.
- DNS yedekleme, Cloudflare uygulama ve geri alma işlemleri sağlamlaştırıldı.
- Başarılı profilin Windows hizmeti olarak otomatik başlaması eklendi.
